05 Spacing

4px를 기본 단위로 하는 4pt 그리드를 씁니다. 연구소의 정돈된 인상은 여백의 규칙성에서 나옵니다 — 임의의 px값 대신 아래 스케일 안에서만 고릅니다.

4xs · 아이콘 내부 여백
8sm · 배지 내부, 인접 요소 간격
12md · 버튼 내부 여백
16base · 카드 내부 여백(모바일)
24lg · 카드 내부 여백(데스크톱)
32xl · 요소 그룹 간 간격
482xl · 섹션 내부 블록 간격
643xl · 섹션 상하 여백(모바일)
964xl · 섹션 상하 여백(데스크톱)

페이지 구조 기준값

데스크톱
  • 섹션 상하 여백96px
  • 카드 내부 여백24px
  • 버튼 내부 여백12 · 24px
  • 카드 사이 간격16px
모바일 (480px 이하)
  • 섹션 상하 여백64px
  • 카드 내부 여백16px
  • 버튼 내부 여백10 · 20px
  • 카드 사이 간격12px
4의 배수를 벗어난 값(예: 10px, 15px, 22px)은 사용하지 않습니다. 스케일에 없는 간격이 필요하면 가장 가까운 값으로 반올림합니다.
