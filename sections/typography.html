04 Typography

구매자가 실제로 읽는 글자는 전부 한글입니다. 그래서 정보를 전달하는 모든 곳은 Pretendard 하나로 통일하고, 지오메트릭한 Space Grotesk는 로고 옆에 붙는 영문 브랜드 요소에만 씁니다. 컬러의 Core/Event 원칙과 같은 구조입니다 — 가독성이 기본, 브랜드 향은 포인트로만.

타입 스케일

Display쉽게, 즐겁게40 / 800 / -1%
H1상품 상세 타이틀30 / 700 / -1%
H2섹션 제목22 / 600 / -0.5%
H3카드 · 소제목17 / 600 / 0%
Body본문, 상품 설명, 안내 문구15 / 400 / lh 1.7
Caption보조 설명 · 캡션 · 라벨12 / 500 / lh 1.5

한글은 라틴 대비 행간이 좁아 보이므로, 본문은 줄간격 1.6~1.7로 여유 있게 둡니다.

모바일 스케일 — 구매자 대부분이 보는 화면

뷰포트 480px 이하에서는 아래 값으로 전환합니다. Display·H1은 한 단계 낮춰 한 화면에 과도하게 크게 잡히지 않게 하고, Body는 가독성을 위해 크기를 거의 유지합니다.

H3카드 · 소제목17→16 / 600
